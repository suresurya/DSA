Mastering Java I/O

A highly visual, slightly unhinged guide to making Java talk, listen, and not crash immediately.

1 The "Hacker" Phase

Welcome to the matrix. Setup your IDE, put on a hoodie, crack your knuckles, and pretend you're breaching the mainframe (you're actually just writing 'Hello World').

2 The Anatomy of Java

Every Java application is essentially a Russian nesting doll. You have a Class. Inside that class, you have methods. Inside those methods, you put the stuff that actually does things.

// The house where your code lives
public class Main {

    // The front door
    public static void main(String[] args) {
        System.out.println("Mom, I'm a programmer!");
    }
}

3 Making Java Talk (Output)

Want to speak to the console? print() pushes text to the same line. println() drops the mic and moves to a new line.

System.out.print("Hello ");
System.out.println("World");
// Output: Hello World

4 The Sacred Import (Input)

To read user input, you need the Scanner. But wait! You can't just use it. You must summon it from the java.util dimension first. If you forget the import statement, Java will literally throw hands.

// 1. SUMMON THE SCANNER (Do not forget this!)
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // 2. Hand it the microphone (System.in)
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int x = sc.nextInt(); // 3. Capture it

        System.out.println("You entered: " + x);
    }
}
